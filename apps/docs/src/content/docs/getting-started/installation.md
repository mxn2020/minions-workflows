---
title: Installation
description: Install Minions Workflows packages
---

## TypeScript / Node.js

```bash
npm install @minions-workflows/sdk minions-sdk
```

## Python

```bash
pip install minions-workflows
```

## CLI

```bash
npm install -g @minions-workflows/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
