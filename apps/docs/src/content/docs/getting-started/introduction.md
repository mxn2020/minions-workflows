# Minions Workflows

Workflow definitions, step sequences, transitions, and run history

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-workflows/sdk`) — Core library for Node.js
- **Python SDK** (`minions-workflows`) — Python bindings
- **CLI Tool** (`@minions-workflows/cli`) — Command-line interface
- **Web App** — Interactive playground at [workflows.minions.wtf](https://workflows.minions.wtf)
