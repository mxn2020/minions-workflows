# Welcome to Minions Workflows

We're excited to introduce **Minions Workflows** — Workflow definitions, step sequences, transitions, and run history.

## What's Included

- **TypeScript SDK**: `npm install @minions-workflows/sdk`
- **Python SDK**: `pip install minions-workflows`
- **CLI**: `npm install -g @minions-workflows/cli`

## Getting Started

Check out the [documentation](https://workflows.minions.help) for a full guide.
